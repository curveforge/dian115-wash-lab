# 洗版工坊 · DIAN115 插件源

这个仓库是**私人自建插件市场**，供本机 DIAN115 在线安装与更新使用。

## 添加来源

DIAN115 面板 → 插件中心 → 用户插件 → 商店（右下角入口）→ 添加来源，填入：

```
https://raw.githubusercontent.com/curveforge/dian115-wash-lab/main/index.json
```

## 更新方式

插件卡片出现“有更新”时点更新即可。更新为原地升级：插件数据、配置、已授权权限保留。

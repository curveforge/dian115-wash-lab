# 洗版工坊 · DIAN115 插件

按「**每一季自己的多数规格**」对齐 Emby 媒体库：把和同季大多数不一样的集挑出来，自动去 115 找资源、解锁、转存，交给 DIAN115 整理。

目标不是「全部洗成 4K」，而是**让同一季的每一集看起来一样**。

- 当前版本：**1.10.3**
- 宿主要求：DIAN115 插件 API **3.13+**
- 包格式：`protected-v4`（平台正式编译 + 本机签名）

---

## 安装

### 方式一：添加插件源（推荐，可自动更新）

DIAN115 → 插件中心 → 用户插件 → 右下角进入商店 → 添加来源：

```
https://raw.githubusercontent.com/curveforge/dian115-wash-lab/main/index.json
```

列表里出现「洗版工坊」后点安装。以后有新版本，同一张卡片点更新即可，插件数据与权限保留。

### 方式二：本地安装包

从 [`packages/`](packages/) 下最新 `.dian115p`，在插件中心用「从本地文件安装」导入。

### 安装后需要配一样东西

**Emby 地址 + 只读 API Key**（插件「设置」页）：

> Emby 后台 → 设置 → 高级 → API 密钥 → 新建

Key 只保存在插件的加密存储里，用于逐集读取媒体信息（只读）。115 账号不用配，插件用的是宿主已登录的 DIAN115 账号。

---

## 它做什么

1. **扫描**：读取 Emby 全库逐集媒体信息，按季统计「多数规格」。
2. **列差异**：把与多数不同的集列出来，标明差在哪个维度。
3. **洗版**：按差异去搜 115 资源，只接受与该季目标规格一致的候选，解锁后转存到「资源」目录，由 DIAN115 自己整理入库。

整个流程**不删除、不改名**任何已有文件；转存是往你自己的 115 网盘里新增文件。

---

## 判定规则（为什么不是「画质越高越好」）

每集提取 8 个维度的指纹：

| 维度 | 取值来源 |
| --- | --- |
| 分辨率 / 视频编码 / 音频（含声道）/ 位深 / 帧率 | 真实媒体流 |
| HDR | 文件名标签（媒体流常缺失，默认成 SDR 会大面积误判） |
| 片源（WEB-DL / BluRay / REMUX…） | 文件名 |
| 字幕（有无中文） | 真实媒体流中的字幕轨 |

规则：

- **逐季取众数**。同一部剧各季规格经常不同，拿全剧多数当标准会把内部自洽的季误报成「整季待换」。
- 覆盖率不足 60% 的维度不参与判定；平票的维度不算多数。
- 缺失该维度信息的集单独计数，**不计入待统一**。
- 候选必须与该季目标**一致**（优先全部命中），差一项也不自动转存——差一项等于没洗成。
- 所以：**1080p BluRay 会压过 4K WEB-DL**。这是刻意的，不是 bug。

没有手选开关：编码、中字、体积上限都不需要选，全部由该季多数决定。

---

## 行为边界

- **只读**访问你配置的 Emby。
- 只向 115 转存（写入整理规则的「资源」目录），不删除、不改名、不移动已有文件。
- 同一分享不会重复接收；已尝试过的资源会记录，避免反复转存。
- 整理入库由 DIAN115 队列完成，有延迟；洗版提交完即结束，不等整理。

## 常见问题

**Q：装了搜不到资源？**
资源池小的剧，全站可能只有个位数候选。插件会如实报「没有找到可用候选」，不会用低一档的资源凑数。

**Q：转存成功但 Emby 里没变？**
整理是队列轮询的，大包要十几分钟到半小时。等整理记录里出现这部剧后，在插件里点一次「复验」（会先让 Emby 重扫）。

**Q：为什么判我要洗的集和我感觉的不一样？**
判定只看上面 8 个维度、按季多数。点开剧集详情可以看到每一集具体差在哪一维。

**Q：换季/换源后想重试某部剧？**
「设置 → 已尝试过的资源 → 清空记录」。
